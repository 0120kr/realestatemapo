      에어코리아 실측값 꺼짐

      공공데이터포털 인증키로 가까운 에어코리아 측정소의 실제 값을 받아와요. 앱에 기본 키가 들어 있으면 따로 넣지 않아도 돼요. 다른 키를 쓰려면 넣고 저장하세요. 칸을 비우고 저장하면 기본 키로 돌아가요.

      현재값은 인증키를 넣으면 한국환경공단 에어코리아 측정소 실측값을 써요. 예보와 키가 없을 때의 값: Open-Meteo 대기질 API (유럽 코페르니쿠스 CAMS 예측 모델). 측정소 실측값이 아니라 모델 추정값이라 에어코리아 측정값과 차이가 날 수 있어요. 위치 이름은 BigDataCloud, 장소 검색은 OpenStreetMap·Photon(© OpenStreetMap 기여자)을 써요. 광고와 추적 코드는 없어요.
